# ☕ Cozy Cafe

A cozy productivity web app inspired by the Forest app 🌿  
Designed to make focus feel warm, calm, and meaningful.

## 🌍 Live Demo
https://cozy-cafe-uwwi.onrender.com/

---

## ✨ Features

- 🔥 Pomodoro Focus Mode  
  Stay focused while your "cafe oven" runs your session  

- 🧾 Task Management (Ingredients List)  
  Add, complete, and delete tasks  

- ✨ Habit Tracker (Cafe Rituals)  
  Build daily habits with simple tracking  

- 📜 History Tracking  
  View completed tasks and habits with dates  

- 💬 Motivational Quotes  
  Random cozy quotes to keep you going  

- 🎨 Cozy UI  
  Soft colors and minimal design for a calm experience  

---

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express  
- **Templating:** EJS  
- **Deployment:** Render  

---

## ⚠️ Note

This app uses a local JSON file for data storage.  
On deployment platforms like Render, data may reset occasionally.
